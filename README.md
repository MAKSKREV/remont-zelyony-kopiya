# Ремонт под ключ

Сайт ремонтной компании: услуги, калькулятор, фильтрация интерьеров, галереи, тарифы и формы.

## Запуск

`npm ci` и `npm run dev`, затем http://localhost:3000/.

## GitHub Pages

Публикация: https://makskrev.github.io/remont-zelyony-kopiya/ . При обновлении main GitHub Actions собирает только сайт. Посторонние презентации и документы из исходного репозитория в публикацию не попадают.

`GITHUB_PAGES=true npm run build:pages` собирает статическую версию с корректным путём `/remont-zelyony-kopiya/`.

Калькулятор, галереи, фильтры и навигация работают на GitHub Pages. Express API и ключи ИИ там недоступны: форма честно сообщает, что отправка не выполнена, сохраняет введённые данные и не показывает выдуманное подтверждение. Локальный запуск сохраняет серверные функции. Для приёма реальных заявок и онлайн-консультанта необходим отдельный сервер.

Фотографии интерьеров из прежней подборки проверены, неподходящие фасады и битая ссылка исключены. Изображения оптимизированы и хранятся в `public/images/`, исходные ссылки — `sources.json`. Это иллюстрации направлений ремонта, а не подтверждение выполнения изображённых объектов компанией.
